# 等待事项规则

每个等待事项必须记录：

| 字段 | 要求 |
|---|---|
| 等待对象 | 明确到外部或内部责任方 |
| 等待原因 | 说明缺少的确认、资源或决定 |
| 开始时间 | 可核实的等待起点 |
| 截止时间 | 最晚确认或处理时间 |
| 下一次动作 | 到期前后的具体动作 |
| 超时动作 | 升级、替代、暂停或退出 |
| 是否升级 | 判断影响和最晚升级时间 |

## 规则

1. 区分“等待外部”和“内部阻塞”。
2. 缺少截止时间时标记缺失，不得无限保留。
3. 超时后必须重新判断价值、风险和继续投入条件。
4. 重大影响且内部协调失败时推荐 `zayn-escalate`。
