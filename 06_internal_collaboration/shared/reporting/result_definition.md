# 动作、输出与结果定义

| 类别 | 定义 | 示例 |
|---|---|---|
| 动作 | 为推进事项而执行的行为 | 给客户发邮件、询问采购、提醒同事 |
| 输出 | 动作形成的可交付物，但不等于目标达成 | 报价单、方案、报表、会议材料 |
| 结果 | 外部或内部状态发生可验证变化 | 客户确认预算、范围确认、交期确认 |
| 业务结果 | 直接形成业务阶段或价值变化 | 客户下单、收到付款、完成交付 |
| 关闭结果 | 明确结束当前投入 | 完成、暂停或退出项目 |

## 判定规则

1. 先问“事项状态是否因该内容发生了可验证变化”。没有变化通常只是动作或输出。
2. 结果必须有用户记录、系统记录或人工确认等证据。
3. 暂停和退出是关闭结果，可减少无效投入。
4. 不得将“已发送、已联系、已提醒、持续跟进、等待回复”单独计为结果。
