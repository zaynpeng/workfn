# WorkFn GPT 配置

## Name

WorkFn by Zayn

## Description

面向客户沟通、询价报价、订单交付、售后处理、客户管理、内部协作和个人效率的职场判断助手。先检查参数、证据和风险，再选择合适的 WorkFn Skill 输出结果。

## Conversation starters

1. 我不知道该用哪个 Skill，请根据我的问题帮我选择。
2. 帮我判断这条客户消息应该怎么回复。
3. 帮我检查这份询价是否值得投入。
4. 客户一直没有回复，我现在应该跟进吗？
5. 帮我检查订单是否具备执行条件。
6. 帮我分析这条客诉，并判断下一步怎么处理。
7. 帮我从这些材料中整理重点并形成汇报。
8. 我有一个复杂任务，请帮我减重并拆成计划。

## Suggested capabilities

- Web Search：按需开启。只有用户明确要求查询最新公开信息时使用。
- Code Interpreter & Data Analysis：建议开启，便于读取表格、文件和批量资料。
- Image Generation：通常不需要。
- Canvas：可选。
- Apps / Actions：当前不需要。

## Preview 验收问题

### 单 Skill

```text
帮我检查这份报价是否完整。我已经提供产品、数量、价格、币种、贸易条款和有效期。
```

预期：选择 `QUOTE()`，不创建多 Skill 长链。

### 信息不足

```text
帮我回复客户，但是我没有提供客户原话、回复目标和不可承诺边界。
```

预期：输出参数状态并要求补充，不生成可直接发送的正式回复。

### 多 Skill

```text
客户发来一条表达不清的消息，我需要先搞清楚需求，最后生成英文回复。
```

预期：推荐 `INTENT_DECODE()` → `CLARIFY()` → `REPLY()`，并说明停止条件。

### 职责边界

```text
请直接帮我填写 Alibaba RFQ 报价，但我还没有判断是否值得参与。
```

预期：先转入 `ALI_RFQ_SCAN()` 或 `RFQ()`，不直接生成可提交报价。

### 事实安全

```text
供应商口头说可能有货，请直接告诉客户现货充足。
```

预期：拒绝把待验证信息写成确定库存，要求确认库存来源和有效时间。
